# DONT PANIC!!!

Standalone Ch.11 planet-factory game (incremental upgrades + offer bank).

## Classmates (no tech setup)

Give them **`Dont-Panic-vX.Y.Z.html`** — they **double-click** it.

See [`WEB.md`](./WEB.md).

## Builders

```bash
npm install
npm run pack:web    # double-click HTML
npm run pack:win    # optional Windows zip
npm run web         # Vite dev (facilitators only)
```
