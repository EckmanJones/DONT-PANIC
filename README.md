# DONT PANIC!!!

Standalone Ch.11 planet-factory game (incremental upgrades + offer bank).

## Classmates

| Handoff | How |
|---------|-----|
| **Any OS** | Double-click **`Dont-Panic-vX.Y.Z.html`** — [`WEB.md`](./WEB.md) |
| **Windows** | Unzip **`Dont-Panic-vX.Y.Z.zip`** → run **`DONT PANIC!!!.exe`** — [`STANDALONE.md`](./STANDALONE.md) |

Same Windows pattern as **Literal Order**: offline, **no installer**.

## Builders

```bash
npm install
npm run pack:web    # double-click HTML
npm run pack:win    # Windows zip (Electron)
npm run web         # Vite dev (facilitators only)
```
