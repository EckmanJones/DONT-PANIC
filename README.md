# DONT PANIC!!!

Standalone project — Blocher **Chapter 11** planet-factory game (mice / Custom Worldworks). Incremental upgrades, custom offer bank, forge sell-or-process.

**Not part of Class-Notes.** Clone this repo and run locally.

## Local web (Mac / Linux / anyone with Node)

```bash
npm install
npm run web
```

Open http://127.0.0.1:1440

Or unzip CI artifact `Dont-Panic-web-vX.Y.Z.zip` → `node serve.mjs`.

## Windows zip (optional)

Unzip `Dont-Panic-vX.Y.Z.zip` → run `DONT PANIC!!!.exe`.
